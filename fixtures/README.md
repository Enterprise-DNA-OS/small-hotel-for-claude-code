# Test files

Used by `npm test`. Fictional records only.

- `little-hotelier/reservations.csv`: a reservations export using column names common in Little Hotelier's reports (yours may differ; the importer accepts several names for each field), with a masked guest (Little Hotelier masks guest details 180 days after check-out), a cancelled booking, a room type and a channel that do not exist yet, and day-first dates.
- `ical/airbnb-unit-7.ics`: an Airbnb host calendar for one listing, the file you get from the listing's calendar export link.
