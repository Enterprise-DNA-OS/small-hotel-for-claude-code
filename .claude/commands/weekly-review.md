# Weekly review

Read CLAUDE.md first. Use fresh data and run:

```bash
npm run hotel -- weekly-review
```

Write a one-page plan: problems to clear, weeks that look soft and what to do about them (a rate change, a direct-booking push, a minimum stay to lift), deposits to chase, and which channel is costing most in commission. Offer to save it to drafts/.

Answer in plain language, tables for numbers, in the property's currency. Ambiguous names list the candidates and exit 1: ask which one. Never invent a booking, a rate, a payment or a guest detail. Nothing here sends a message or charges a card: drafts go to drafts/ and a person acts.
